以Transformer为线索、最大化复用已有知识的串行学习路径。

AI技术深度进阶路线图（Transformer主线版）

核心理念

你已掌握Transformer这把“万能钥匙”，视频AI = Transformer + 三个扩展模块

扩展模块 解决的问题 学习时长
视觉编码 图像/视频如何变成序列 第1月
多模态对齐 视觉与语言如何交互 第2-3月
时序建模 帧与帧之间的关系 第4月（理解）+ 第6-7月（生成）
扩散机制 如何生成图像/视频 第5-7月

总体安排（8个月串行）

阶段 时间 核心方向 核心任务 产出
第一阶段 第1-2月 视觉编码与对齐 ViT、CLIP、多模态基础 理解图像→序列的转换
第二阶段 第3-4月 多模态大模型 LLaVA/Qwen-VL微调 + Java工程化 银行合规审核平台
第三阶段 第5-6月 扩散模型与视频生成 Diffusion、DiT、SVD、AnimateDiff AI视频生成工具
第四阶段 第7-8月 融合与冲刺 多模态+视频生成融合项目 + 面试 AI广告生成平台

第一阶段：视觉编码与对齐（第1-2月）

目标

理解图像/视频如何转换为Transformer可处理的序列，以及视觉与语言如何对齐。

第1个月：ViT与视觉编码

周次 内容 具体任务 Transformer关联
第1周 ViT原理 精读ViT论文；理解patch切分、位置编码；对比ViT与原始Transformer的异同 输入从词变为图像patch
第2周 ViT实战 跑通ViT分类demo；可视化attention map 观察Transformer如何“看”图像
第3周 视觉编码器演进 学习Swin Transformer（层级化）、MAE（掩码自编码） 视觉Transformer的优化变体
第4周 视频视觉编码 学习VideoViT；理解如何将视频帧序列输入Transformer 从2D扩展到3D

本月产出：深入理解ViT架构，能独立跑通ViT分类任务

第2个月：CLIP与多模态对齐

周次 内容 具体任务 Transformer关联
第1周 CLIP原理 精读CLIP论文；理解对比学习、双塔架构；手推contrastive loss 双塔Transformer，各自编码图文
第2周 CLIP实战 跑通CLIP图文检索；实现zero-shot图像分类 理解图文对齐后的能力
第3周 多模态对齐机制 学习BLIP/BLIP2的Q-Former；理解如何压缩视觉特征 新增的Transformer变体模块
第4周 阶段性整合 用CLIP + ViT搭建一个图文检索系统 端到端实践

本月产出：深入理解CLIP，能搭建图文检索系统

第二阶段：多模态大模型（第3-4月）

目标

掌握多模态大模型架构，完成微调与Java工程化落地。

第3个月：LLaVA与多模态大模型

周次 内容 具体任务 Transformer关联
第1周 LLaVA架构 精读LLaVA论文；理解“ViT + 投影层 + LLM”三板斧 在你已有的LLM知识上增加视觉输入
第2周 LLaVA实战 跑通LLaVA推理；理解视觉token如何送入LLM 观察视觉与文本的融合
第3周 微调技术 LoRA、QLoRA原理；在自定义数据上微调LLaVA 高效微调Transformer
第4周 Qwen-VL 对比Qwen-VL与LLaVA；理解中文多模态模型的特性 企业级多模态模型选型

本月产出：微调后的多模态模型，能完成票据OCR任务

第4个月：Java工程化与项目整合

周次 内容 具体任务 Java工程化重点
第1周 模型部署 vLLM/TGI部署多模态模型；ONNX导出 GPU推理服务
第2周 Java调用 Spring Boot封装；HTTP/gRPC接口设计 服务层架构
第3周 多模态RAG Milvus向量数据库；多模态检索 图文混合检索
第4周 项目整合 银行合规审核平台：票据OCR + 合规校验 + 报告生成 端到端交付

最终项目：银行多模态合规审核平台

  • 输入：合同/票据扫描件
  • 处理：OCR → Qwen-VL抽取关键字段 → 合规规则校验
  • 输出：合规报告 + 异常告警
  • 技术：Qwen-VL微调 + Milvus + Java Spring Boot

第三阶段：扩散模型与视频生成（第5-6月）

目标

掌握扩散模型原理，深入视频生成核心模型。

第5个月：扩散模型基础

周次 内容 具体任务 Transformer关联
第1周 扩散模型原理 DDPM论文精读；理解前向扩散与反向去噪 新架构，但DiT正在引入Transformer
第2周 Stable Diffusion 理解VAE + UNet + CLIP text encoder架构；跑通SD推理 CLIP复用
第3周 ControlNet 条件控制生成；跑通Canny/Depth控制 扩展现有能力
第4周 DiT 精读DiT论文；理解Transformer如何替代UNet Transformer回归核心

本月产出：深入理解扩散模型，能跑通SD + ControlNet

第6个月：视频生成核心模型

周次 内容 具体任务 新增概念
第1-2周 Stable Video Diffusion 精读论文；跑通图生视频；理解帧间一致性 时序建模引入
第3-4周 AnimateDiff 精读论文；跑通文生视频；理解Motion Module 时序注意力模块

本月产出：能生成2-4秒短视频，支持文生视频和图生视频

第四阶段：融合与面试冲刺（第7-8月）

目标

融合多模态理解与视频生成能力，完成亮点项目，准备面试。

第7个月：融合项目开发

周次 内容 具体任务
第1-2周 项目设计 AI广告视频生成平台架构设计
第3-4周 项目实现 端到端开发 + 测试 + 优化

融合项目：AI广告视频生成平台

text

  • 可演示的端到端系统

第8个月：面试冲刺

周次 内容 具体任务
第1周 项目复盘 三个项目文档化（合规审核、视频生成、融合平台）

第3周 系统设计准备 多模态审核系统、视频生成平台架构设计
第4周 模拟面试 技术深度的表达训练
