Vision Transformer (ViT)

参考论文：An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale，ICLR 2021
核心结论：把图像切成固定大小的 patch 后，几乎不引入卷积先验，直接使用标准 Transformer Encoder，也能在大规模预训练后达到或超过强 CNN 基线，并且训练计算成本更低。

0. 一句话理解

ViT 把一张图像切成一串 16x16 的 patch，把每个 patch 当作 NLP 里的 token，再交给标准 Transformer Encoder 做分类。

这篇论文的重点不是“发明了复杂视觉模块”，而是证明：

  • 图像不一定必须先经过 CNN 才能用 Transformer。
  • Transformer 缺少 CNN 的局部性和平移等变性，所以小数据上不占优。
  • 当预训练数据足够大时，模型可以从数据中学到视觉结构，规模化训练可以弥补甚至超过手工归纳偏置。

1. 模型整体流程

以 224x224 输入、16x16 patch 为例：

输入图像: 224 x 224 x 3
patch 大小: 16 x 16
patch 数量: (224 / 16) x (224 / 16) = 14 x 14 = 196
每个 patch 展平维度: 16 x 16 x 3 = 768
加上 class token 后序列长度: 196 + 1 = 197
ViT-B/16 的隐藏维度 D: 768
最终 Transformer 输入形状: 197 x 768

2. 四个核心公式

2.1 输入嵌入

$$
\mathbf{z}0 =
[\mathbf{x}{class}; \mathbf{x}_p^1\mathbf{E}; \mathbf{x}_p^2\mathbf{E}; \dots; \mathbf{x}_p^N\mathbf{E}]

  • \mathbf{E}_{pos}
    $$
符号 含义 ViT-B/16 示例
$\mathbf{x}_p^i$ 第 $i$ 个展平后的 patch $1 \times 768$
$\mathbf{E}$ 可训练线性投影矩阵 $768 \times 768$
$\mathbf{x}_{class}$ 可学习的分类 token $1 \times 768$
$\mathbf{E}_{pos}$ 可学习位置编码 $197 \times 768$
$\mathbf{z}_0$ Transformer Encoder 输入序列 $197 \times 768$

关键点：

  • $N = HW / P^2$，其中 $P$ 是 patch 边长。
  • patch embedding 本质上是把每个图像块映射成一个 token embedding。
  • [class] token 继承自 BERT，最后用它代表整张图像。
  • 位置编码默认使用可学习的 1D position embedding，论文发现它与 2D 位置编码、相对位置编码相比没有明显劣势。

2.2 Self-Attention 块

$$
\mathbf{z}’\ell = \mathrm{MSA}(\mathrm{LN}(\mathbf{z}{\ell - 1})) + \mathbf{z}_{\ell - 1}, \quad \ell = 1 \dots L
$$

  • LN：LayerNorm（Pre-LN）

  • MSA：多头自注意力，全局信息交互

  • +残差连接

作用：让每个 patch 能“看到”所有其他 patch，建模全局依赖。

ViT 使用的是 Pre-LN 结构：先 LayerNorm，再进入 MSA，最后做残差连接。这样比原始 Post-LN 更利于深层 Transformer 训练稳定。

2.3 MLP 块

$$
\mathbf{z}_\ell = \mathrm{MLP}(\mathrm{LN}(\mathbf{z}’_\ell)) + \mathbf{z}’_\ell, \quad \ell = 1 \dots L
$$

作用：对每个 token 独立进行非线性变换，增强特征表示。

MLP 是两层全连接，中间使用 GELU：
$$
D \rightarrow D_{MLP} \rightarrow D
$$

在 ViT-B/16 中：

768 -> 3072 -> 768

2.4 分类表示

$$
\mathbf{y} = \mathrm{LN}(\mathbf{z}_L^0)
$$

$\mathbf{z}_L^0$ 表示第 $L$ 层输出序列中的第 0 个 token，也就是 [class] token。它经过最终 LayerNorm 后作为图像表示，再送入分类头。

3. ViT 与原始 Transformer 的对应关系

原始 Transformer / BERT ViT 中的对应物 说明
词 token 图像 patch token 把图像块当作词
token embedding patch linear projection 展平 patch 后线性投影
position embedding patch position embedding 保留空间位置信息
Transformer Encoder Transformer Encoder 几乎原样使用
[CLS] token [class] token 用于整图分类
FFN MLP block 两层全连接 + GELU

本质公式：

ViT = patchify(image) + linear projection + position embedding + Transformer Encoder

4. 模型规模配置

论文基于 BERT 的配置设计 ViT，并额外加入 Huge 版本。

模型 Encoder 层数 L 隐藏维度 D MLP 维度 Attention Heads 参数量
ViT-Base 12 768 3072 12 86M
ViT-Large 24 1024 4096 16 307M
ViT-Huge 32 1280 5120 16 632M

命名方式：

  • ViT-B/16：Base 规模，patch 大小为 16x16。
  • ViT-L/32：Large 规模，patch 大小为 32x32。
  • patch 越小，序列越长，计算越贵；因为 Self-Attention 对序列长度近似是二次复杂度。

5. 归纳偏置：为什么 ViT 需要大数据

CNN 的视觉先验很强：

  • 局部性：卷积核只看邻域。
  • 平移等变性：目标平移后特征响应也相应平移。
  • 层次结构：低层边缘纹理，高层语义对象。

ViT 的视觉先验很弱：

  • 只在输入阶段使用 patch 切分。
  • 只通过位置编码告诉模型 patch 的顺序。
  • Self-Attention 是全局交互，不天然偏向局部邻域。

论文结论很清晰：

数据规模 表现倾向 原因
ImageNet 1.3M CNN / BiT 更强 CNN 先验能提升小数据泛化
ImageNet-21k 14M ViT 开始接近强 CNN 数据规模开始支撑 Transformer
JFT-300M 303M ViT 明显释放潜力 大规模数据弥补归纳偏置不足

可以把它理解为：CNN 把“怎么看图”的经验写进架构，ViT 则尽量少写规则，把学习空间留给数据和规模。

6. 位置编码与高分辨率微调

6.1 为什么需要位置编码

Self-Attention 本身对输入顺序不敏感。如果不加位置编码，模型只知道有哪些 patch，不知道 patch 在图像中的上下左右关系。

论文做法：

  • 默认使用可学习的 1D position embedding。
  • 不使用复杂的 2D-aware position embedding。
  • 附录实验显示：有位置编码明显优于没有位置编码；但 1D、2D、相对位置编码之间差异很小。

论文观察到，训练后的位置编码会自然呈现 2D 结构：相邻 patch 的位置向量更相似，同一行、同一列也会表现出相似性。

6.2 高分辨率微调

预训练和微调常使用不同输入分辨率。例如预训练使用 224x224，微调使用 384x384、512x512 或 518x518。

处理方式：

  1. 保持 patch 大小不变。
  2. 输入分辨率变大后，patch 数量变多，序列长度随之变长。
  3. Transformer 可以处理更长序列，但预训练的位置编码长度不匹配。
  4. 对预训练位置编码按原始二维网格做 2D interpolation，映射到新分辨率网格。

这是 ViT 中少数显式注入 2D 图像结构的位置之一。

7. 预训练与微调设置

7.1 预训练

论文中的主要设置：

  • 优化器：Adam。
  • batch size：4096。
  • 学习率：warmup 10k steps 后衰减。
  • weight decay：大规模预训练常用 0.1。
  • 训练分辨率：224。

数据集：

数据集 类别数 图像数 作用
ImageNet 1k 1.3M 中等规模基线
ImageNet-21k 21k 14M 公开大规模预训练
JFT-300M 18k 303M 内部超大规模预训练

7.2 微调

论文微调流程：

  • 移除预训练分类头。
  • 替换为新的零初始化线性层，输出目标数据集类别数。
  • 使用 SGD + momentum 0.9。
  • batch size 为 512。
  • 通常使用更高分辨率，例如 384。

注意：预训练阶段的分类头是带一个隐藏层的 MLP；微调阶段论文使用单层线性分类头。

8. 关键实验结论

8.1 与 SOTA 对比

论文中 JFT-300M 预训练的 ViT-H/14 达到：

数据集 ViT-H/14 结果
ImageNet 88.55%
ImageNet-ReaL 90.72%
CIFAR-10 99.50%
CIFAR-100 94.55%
Oxford-IIIT Pets 97.56%
Oxford Flowers-102 99.68%
VTAB 19 tasks 77.63%

同时预训练成本约为 2.5k TPUv3-core-days，低于论文对比中的 BiT-L 9.9k 和 Noisy Student 12.3k。

8.2 数据规模结论

论文 Figure 3 / Figure 4 的核心信息：

  • 小数据预训练时，大 ViT 容易不如小 ViT，也不如 ResNet/BiT。
  • 数据规模变大后，大 ViT 才能超过小模型和 CNN。
  • ResNet 在小数据上更稳，但性能更早平台化；ViT 对规模更敏感，上限更高。

8.3 计算效率结论

论文 Figure 5 的结论：

  • 在 JFT-300M 预训练下，ViT 的性能 / 计算量权衡优于 ResNet。
  • 达到相似迁移性能时，ViT 约少用 2-4x 预训练计算量。
  • Hybrid CNN + ViT 在小计算预算下略好，但模型变大后优势消失。

8.4 模型内部观察

论文对 ViT 内部表示做了分析：

  • 第一层 patch projection 学到类似局部纹理基函数的滤波器。
  • 位置编码会学到二维空间拓扑。
  • 低层部分 attention head 已经能关注很大区域，说明 ViT 真的在使用全局信息。
  • 也有一些低层 head 保持局部注意力，类似 CNN 早期局部特征处理。
  • 随着层数加深，attention distance 整体增大。

9. 工程实现要点

9.1 Patch Embedding 的常见实现

工程上通常不用手写切 patch + flatten，而是用一个卷积等价实现：

Conv2d(
  in_channels=3,
  out_channels=D,
  kernel_size=P,
  stride=P
)

当 kernel_size = stride = patch_size 时，每个卷积窗口正好对应一个 patch，输出再展平成 token 序列即可。

9.2 推理部署注意点

  • 固定输入分辨率时，position embedding 可以直接使用。
  • 动态分辨率或高分辨率迁移时，需要实现位置编码插值。
  • patch 越小，token 数越多，显存和延迟增长明显。
  • ViT-B/16 的参数量约 86M，FP32 大约 344MB；实际部署可用 FP16 / INT8 降低体积。
  • 分类任务直接取 class token；检测、分割任务通常会改造 token 输出或接任务头。

9.3 Patch 大小的权衡

Patch 大小 序列长度 计算成本 表达能力
32x32 短 低 细节较少
16x16 中 中 论文主流配置
14x14 更长 更高 ViT-H/14 精度更强

公式上，序列长度与 $1/P^2$ 成正比：

$$
N = \frac{H}{P} \times \frac{W}{P}
$$

所以把 patch 从 32 降到 16，序列长度会变成 4 倍，Self-Attention 的主要计算会显著增加。

10. 常见疑问

Q1：ViT 为什么把图像切成 patch，而不是直接对像素做 attention？

因为直接把每个像素当 token，序列长度太大。224x224 图像有 50176 个像素 token，Self-Attention 的复杂度接近 $O(N^2)$，不可承受。切成 16x16 patch 后只有 196 个 patch token，计算量大幅下降。

Q2：ViT 相比 CNN 最大的优点是什么？

全局建模能力强，并且架构高度可扩展，可以复用成熟的 Transformer 训练和部署经验。在大规模数据上，ViT 的性能 / 计算量权衡很好。

Q3：ViT 最大的缺点是什么？

缺少 CNN 的视觉归纳偏置，小数据训练时泛化较弱，更依赖大规模预训练、正则化和数据增强。

Q4：为什么 1D 位置编码也能处理 2D 图像？

因为 patch 按 raster order 展平成一维序列后，每个位置仍然唯一对应原图二维坐标。模型可以通过训练从这些位置向量中学习二维拓扑关系。论文实验表明，1D 可学习位置编码已经足够强。

Q5：高分辨率微调为什么要插值 position embedding？

输入分辨率变大后，patch 网格从例如 14x14 变成 24x24，位置编码数量不匹配。需要把预训练得到的二维位置编码网格插值到新的网格大小，否则新位置没有对应的位置向量。

Q6：ViT 中 class token 和 global average pooling 哪个更好？

论文主实验使用 class token，是为了贴近 BERT / Transformer 的文本分类做法。附录实验显示 class token 和 global average pooling 表现接近，但可能需要不同学习率。

11. 易错点

  • ViT 不是没有任何图像先验：patch 切分和高分辨率微调时的位置编码插值都注入了 2D 结构，只是远少于 CNN。
  • 16x16 不是固定要求：论文常用 /16，也有 /32、/14 等配置。
  • ViT 不一定小数据更强：小数据上 CNN 的归纳偏置通常更有优势。
  • 位置编码不是可有可无：没有位置编码会明显变差。
  • Transformer Encoder 几乎原样使用：ViT 的关键创新在输入表示和规模化验证，而不是 Encoder 内部结构。

14. 总结

ViT 的价值在于把视觉识别问题重新表述成序列建模问题：图像被切成 patch 序列，Transformer Encoder 负责全局信息交互，class token 聚合整图语义。它牺牲了一部分 CNN 天生具备的视觉归纳偏置，但换来了更强的规模化能力。论文真正证明的是：当数据和计算规模足够大时，简单、通用、可扩展的 Transformer 架构可以成为视觉识别的强基线。
